# 科研/学习教练（最小原型）

在原 TodoList 和命令行菜单上增量扩展，保留添加、查看、完成、删除及 JSON 列表持久化。Python 3.9+，仅标准库，无 API、无云服务。

## 启动

```bash
python3 todo_app.py
```

原菜单 1–5 不变，新增：6 制定每日计划，7 查看完成情况，8 保存复盘，9 修改优先级/截止日期。P1 最高、P2 普通、P3 低；日期 YYYY-MM-DD，按本机日期处理，日期当天不算逾期。

任务建议写成可检查的成果，例如“完成论文第 2 节推导并核对单位”，而不是“学习物理”。每日计划留空自动选最多三项：先到期/逾期，再优先级，再截止日。也可输入任务编号，如 `1,3`。当天计划确定后不改写，以保留真实完成率。未完成项不会自动算到明天，次日重新制定计划。

复盘保存“成果/卡点”和“下一步”。按计划快照的任务数统计完成率，晚于计划日期完成不计入当天；删除不会抹去计划分母，已完成后删除仍保留计划完成记录。旧任务没有历史完成时间，无法推断何时完成。当前任务当天完成数仅统计仍在任务列表的任务，与计划完成率独立。

```bash
python3 todo_app.py --summary
python3 todo_app.py --summary --date 2026-09-30
python3 -m unittest -v
```

## macOS 主动提醒

先预览，再安装（使用你日常运行项目的 Python）：

```bash
python3 todo_app.py --remind --dry-run
python3 todo_app.py --install-reminders
```

安装用户级 LaunchAgent，每分钟检查：09:00 后未计划提醒，10:00 后到期/逾期提醒，21:00 后未复盘提醒。每类每天最多一次；登录后自动运行，关闭终端仍有效。睡眠/关机时不能通知，唤醒后补检查；安装较晚可能一次补发多类提醒。使用 osascript 系统通知，需允许其通知、关闭专注模式屏蔽。系统命令成功不代表通知一定显示；请在自己的 Mac 上确认。不会强制弹窗或阻止使用电脑。

```bash
python3 todo_app.py --uninstall-reminders
```

移动项目或更换 Python 前先卸载，之后重新安装。路径固定在安装时的绝对路径；不要删除该 Python 环境。错误查看项目内 `reminders.log`。

## 数据与边界

`todos.json` 位于脚本目录，保留原来的列表格式，自动补充稳定 ID、优先级、截止日期、完成时间；`coach.json` 保存计划快照、复盘和提醒去重记录。若此前从其他工作目录运行，请先把原 `todos.json` 复制到脚本目录，备份两个 JSON 后再升级。首次交互启动会保存兼容迁移；损坏 JSON 报错退出，避免静默覆盖。

所有入口使用同一个文件锁避免菜单与后台同时写入；交互菜单打开时后台提醒会跳过，关闭后下次检查继续。JSON 使用临时文件原子替换；两个 JSON 并非跨文件事务。仅面向本地单用户，勿用云盘同步并行修改或直接调用类方法绕过入口锁。

这是基于规则的最小教练原型，不调用大模型。当前支持任务推进、计划约束和复盘提示，尚不分析论文或自动拆解科研任务。
